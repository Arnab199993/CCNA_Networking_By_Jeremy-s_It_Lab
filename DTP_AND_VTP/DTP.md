# DTP (Dynamic Trunking Protocol)
Ans : DTP is a cisco propeitori protocol that allows switches to negotiate the status of their switchport to be either access port or trunk port, without manually configuring them.

# VTP (VLAN Trunking Protocol)
Ans : VTP is another Cisco Propertori Protocol that allows you to configure VLAN on a central switch, which then acts as a server that other switches can synchronize to, so you dont have to configure VLANs on every single switch on the network.

DTP is enabled on by default.
