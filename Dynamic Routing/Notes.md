# OSPF is a link state dynamic routing protocol

# Distance Vector, Link State, Path Vector (Algorithm Type)

# 1. IGP ---> Distance Vector and Link State ---> Distance Vector ----> Routing information Protocol (Rip) & Enhance Interior Gateway Routing Protocol (EIGRP)

# 2. IGP ---> Distance Vector and Link State ----> Link State ----> Open Shortest Path First (OSPF) & Immediate system to intermediate system (IS - IS)

# 3. EGP ----> Path Vector ---> Border Gateway Protocol (BGP)

EGP's are used to share routes between different autonomous system
IGP's are used to share routes within a single autonomous system, which is a single organization

All routing protocols have same goals. To share route information and select the best route to each destination.
